This repo documents **Week 3** of my Cybersecurity & Ethical Hacking internship with
NetworkWalks Academy (Batch B082). This module covers **password cracking** — using
**John the Ripper (JTR)** and its graphical front-end **Johnny** to recover the passwords
of encrypted PDF files, then opening each file to confirm the result.

Password cracking is how a security tester measures whether a password is actually strong.
The same method an attacker would use to break into a protected file is used here, under
authorization, to show **why weak passwords fail** and why strong ones matter.

---

## ⚠️ Authorization & Scope

All files cracked here are **practice PDFs provided by NetworkWalks** as part of the B082
internship — they are deliberately locked as a training (capture-the-flag) exercise.

**In scope:**
- The course-provided practice PDFs (`My Locked PDF1.pdf`, `PDF2`, `PDF3`), cracked on my
  own lab machine.

Nothing else was tested — no third-party files and no unauthorized systems, only the
training material I was given, on hardware I own and control.
